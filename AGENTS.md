# Instructions permanentes pour Codex — Projet Agone / Atamore

## Source de vérité éditoriale

Avant toute modification du site, lire intégralement :

1. `docs/ALPHA_EDITORIAL_HANDOFF.md`
2. `docs/CANON_SOURCE_PACK.md`

Ces fichiers constituent le corpus éditorial de référence dérivé des sources de campagne et des corrections de l’utilisateur.

## Règles

- Ne pas inventer pour combler un vide documentaire.
- Ne pas résoudre silencieusement une contradiction de nom, date ou version.
- Ne pas transformer une hypothèse d’Atamore en vérité canonique.
- Ne pas donner à Atamore une connaissance qu’il n’avait pas encore à la date concernée.
- L’aventure d’Abyme 1444 est un flashback **encore en cours de jeu** : ne jamais écrire sa suite.
- Pour l’alpha, conserver autant que possible le design existant ; privilégier l’intégration éditoriale plutôt qu’une refonte gratuite.
- Travailler sur la branche `alpha-editoriale` tant que l’utilisateur n’a pas validé la fusion.
- Préserver la compatibilité GitHub Pages.

## En cas de doute

Si une information n’est pas présente dans `docs/ALPHA_EDITORIAL_HANDOFF.md` ou `docs/CANON_SOURCE_PACK.md`, ne pas l’inventer. Laisser le point comme inconnu / à confirmer dans le code ou le contenu.
